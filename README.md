# Hello, World! in 13 Programming Languages

By **Braxten Orline Urdelas** — 1st Year BSIT

A small practice project. Every file in this folder prints the same
four lines, just written in a different programming language:

```
Hello, World!
I'm Braxten Orline Urdelas!
Someday I will become a successful Professional
and be known for my skills and intellect.
```

## Languages used

| File | Language |
|---|---|
| `hello.c` | C |
| `hello.cpp` | C++ |
| `hello.cs` | C# |
| `HelloWorld.java` | Java |
| `hello.py` | Python |
| `hello.js` | JavaScript |
| `hello.rb` | Ruby |
| `hello.go` | Go |
| `hello.rs` | Rust |
| `hello.swift` | Swift |
| `Hello.kt` | Kotlin |
| `hello.asm` | Assembly (x86-64) |
| `hello.html` | HTML |
| `hello.css`  | CSS |

Each file has a comment at the top with the command to run it.
